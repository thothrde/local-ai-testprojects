Datenschutz

Diese Anwendung erhebt durch ihren eigenen Programmcode keine personenbezogenen Daten. Die Berechnungen erfolgen lokal im Browser.

Keine eigenen Tracking-Dienste

Die Anwendung verwendet keine eigenen Cookies, keine Analyse- oder Trackingwerkzeuge und keinen lokalen Nutzerspeicher (localStorage). Eingabewerte können im URL-Fragment gespeichert werden, wenn die Anwendung den aktuellen Rechenstand in der Adresse abbildet; dieses Fragment wird nach den üblichen Browserregeln nicht als Teil der HTTP-Anfrage an den Webserver übertragen.

Hosting über GitHub Pages

Die Website wird über GitHub Pages bereitgestellt. Nach der Dokumentation von GitHub wird beim Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert, unabhängig davon, ob eine Anmeldung bei GitHub besteht.

Weitere Informationen: GitHub Pages – Datensammlung ↗ und GitHub-Datenschutzerklärung ↗.

Geteilte Links

Der Link „Link mit Werten kopieren“ enthält Ihre eingegebenen Zahlen im URL-Fragment hinter dem „#“. Wer den Link erhält, sieht diese Werte. Teilen Sie den Link deshalb nur mit Personen, denen Sie die Werte zeigen möchten.

Rechtsgrundlage

Diese Website setzt keine Einwilligungsabfrage ein, weil sie selbst keine personenbezogenen Daten verarbeitet. Soweit der Hosting-Anbieter GitHub beim Aufruf der Seite die IP-Adresse verarbeitet, geschieht dies nach seinen Angaben zur Sicherheit und zur zuverlässigen Bereitstellung des Dienstes. Als Rechtsgrundlage kommt insoweit ein berechtigtes Interesse nach Art. 6 Abs. 1 lit. f DSGVO in Betracht. Mir liegen keine Zugriffsprotokolle und keine Besucherstatistiken dieser Seite vor.

GitHub Pages wird von GitHub, Inc. (USA) betrieben. Beim Aufruf dieser Website kann Ihre IP-Adresse daher an Server in den USA übermittelt und dort protokolliert werden. Nach eigenen Angaben ist GitHub dem EU-U.S. Data Privacy Framework beigetreten. Für zertifizierte Unternehmen hat die Europäische Kommission mit dem Durchführungsbeschluss (EU) 2023/1795 vom 10. Juli 2023 ein angemessenes Datenschutzniveau festgestellt. Daneben stützt sich GitHub nach seiner Datenschutzerklärung in der Regel auf die Standardvertragsklauseln der EU-Kommission (Durchführungsbeschluss (EU) 2021/914). Diese Angaben von GitHub habe ich zuletzt am 2. November 2026 gelesen; maßgeblich ist die jeweils aktuelle GitHub-Datenschutzerklärung ↗.
