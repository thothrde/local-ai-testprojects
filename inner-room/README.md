# THE INNER ROOM

Public static files for **THE INNER ROOM — An Atlas of Solitary Minds**.

Canonical site: https://thomas.autark-data.org/inner-room/

This repository is intentionally a **public deployment artifact only**. Editorial source data, research workflow metadata, build/test machinery and release-audit material are kept outside the public repository. The public app contains only original paraphrases and interpretations, never direct literary quotations or book-page images.
