# Damascius Atlas — Public Bilingual Edition v1.1.0

A single-file, offline-capable, bilingual visual atlas of Damascius’ *Philosophical History*.

## Public deployment
Upload `index.html` and the licence/notice files. Do **not** upload `Damascius-History.pdf`
or any other modern scan.

## Local start
Double-click `index.html` or run:

```bash
open index.html
```

## Optional private research PDF
Use “Connect local PDF”. The selected file remains in the current browser tab and is not uploaded.
